# Мониторинг воздушных судов

## Описание проекта

Программа для сбора данных о самолетах, находящихся в воздушном пространстве выбранных стран. Данные получаются с помощью внешних API:
- **Nominatim OpenStreetMap** — для получения географических координат (bounding box) страны
- **OpenSky Network** — для получения информации о самолетах в реальном времени

## Функциональность

- Поиск самолетов по названию страны
- Сохранение данных в JSON-файл и CSV форматах
- Сортировка самолетов по высоте и скорости
- Фильтрация по стране регистрации и диапазону высот
- Вывод топ N самолетов
- Статистика по сохраненным данным
- Удобный консольный интерфейс

## Установка и запуск

### Требования
- Python 3.9 или выше
- Poetry

### Установка зависимостей

```bash
poetry install
```
### Запуск программы
```bash
poetry run python main.py
```
### Запуск тестов
```bash
poetry run pytest --cov=src
```
